# Insta AprovaJá

Aplicativo gratuito para planejar, redigir, padronizar e organizar publicações do perfil **AprovaJá Concursos** (`@aprovaja_seuconcurso`).

## Objetivo da primeira versão

- Calendário editorial com três publicações por semana.
- Geração assistida de ideias, legendas e chamadas para ação por modelos de prompt (sem API paga).
- Fila de aprovação manual.
- Prévia de publicação e cópia de legenda.
- Identidade visual azul e laranja.
- Dados armazenados localmente no navegador nesta versão inicial.

## Como executar

Abra `index.html` no navegador ou ative GitHub Pages em **Settings → Pages** e selecione a branch `main`, pasta `/ (root)`.

## Limitações atuais

Esta primeira versão não publica diretamente no Instagram, não chama uma API de IA e não sincroniza dados entre dispositivos. A publicação automática exigirá integração autorizada com a API oficial da Meta e configuração segura de credenciais no servidor. Nenhuma senha ou token deve ser colocado neste repositório.
